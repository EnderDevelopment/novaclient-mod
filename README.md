# NovaClient Mod

Enhance your Minecraft experience with NovaClient Mod, a Fabric mod that adds a custom HUD, GUI, and configuration system.

## Features

- Custom HUD display
- Configurable GUI with keybindings
- Persistent configuration system

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.19.2
- Java 21

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

- Press the RIGHT_SHIFT key to toggle the NovaClient GUI.
- Configure the mod settings through the GUI.

## Configuration

The mod's configuration is saved to `config/novaclient.json`. You can manually edit this file to change settings.
